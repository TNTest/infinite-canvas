# 待测试

## 用户 API Key

- 账户菜单新增 API Key 管理入口：创建多个 Key、查看前缀和最近使用时间、删除撤销；完整密钥仅创建时显示一次。
- 有效期支持永久和自定义未来时间；每位用户最多保留 100 个未删除 Key，已过期条目仍计数，删除后可继续创建。
- 使用 `Authorization: Bearer <Key>` 调用已有后端接口，继承所属用户的当前权限、配置和算力点；普通用户不能访问管理员接口。
- 人工验收：账户菜单与画布菜单入口、创建后的复制、关闭后不再显示完整密钥、失效时间显示、撤销确认、数量达到 100 后的提示。
- 接口与数据库说明见 [接口响应约定](../backend/api-response.md#用户-api-key) 和 [数据库说明](../backend/backend-database.md)。

本地验证已通过：Go 全量测试、API Key 并发上限和权限隔离测试、Comfy Bridge Go 测试、前端生产构建，以及浏览器创建/指定有效期/关闭隐藏明文/撤销和前端代理真实 HTTP 鉴权。复制按钮已触发成功提示，自动化浏览器未能读取系统剪贴板内容，仍需用户确认实际粘贴结果。
