# 待测试

## 用户 API Key

- 账户菜单支持创建、查看、撤销 Key；新 Key 支持列表再次复制，旧哈希 Key 提示重建，最多 100 个未删除 Key，失效时间支持永久和自定义。
- 权限分为只读、生成、写入和删除，默认只读＋生成；删除单独授权，未知路由默认不开放。
- 后台、Key 管理、个人模型/存储配置及 Bridge 管理只允许登录会话，管理员 Key 同样受限；个人 Bridge 随所属用户禁用或删除而拒绝认证。
- 每个 Key 可设置每分钟请求上限和累计次数额度，列表展示用量，调用记录展示最近 100 条 HTTP 状态和耗时；每用户最多保留 10000 条并自动淘汰，不记录密钥、请求正文或查询参数。
- 鉴权数据库异常返回 503、权限不足 403、限流 429；通用 AI 转发补充连接失败、超时、SSE 错误及流中断处理。客户端交付失败只记录错误，不因主动断连自动退款。
- 人工验收：四项权限默认值和独立勾选、RPM/累计额度输入、永久/定时失效、创建后的实际复制粘贴、调用后刷新用量与记录、撤销确认、关闭或切换身份后清理临时完整密钥与日志。
- 接口与数据库说明见 [接口响应约定](../backend/api-response.md#用户-api-key) 和 [数据库说明](../backend/backend-database.md)。

上游基线有 17 处 TypeScript 错误及 4 条模型渠道相关前端测试失败，均在本次未修改的文件中；现有生产构建配置跳过 TypeScript 类型错误。测试使用本地 SQLite 和模拟上游，不代表真实模型供应商、S3/WebDAV、MySQL/PostgreSQL 的生产端到端验收。

本地验证已通过：

- `go test ./...` 后端全量回归。
- 99 条受保护/可选鉴权路由（包含新增复制接口）的准入矩阵：独立权限、读写组合、全权限 Key、用户/管理员会话、游客；矩阵末端使用无副作用处理器，不能视为 98 个业务接口完整验收。
- 真实 Gin + API Key + 模拟上游的图片、聊天、音频与正常流调用；上游认证错误、限流、服务器错误、超时、连接失败、SSE 错误帧和读取中断；客户端断开/短写保留扣点，已测真实失败不重复退款。
- 并发创建上限、RPM 和累计请求额度、审计保留上限与用户隔离、撤销/到期/用户禁用删除、个人 Bridge 生命周期；核心并发用例的 race 检查通过。
- 前端生产构建与修改文件的格式检查；浏览器空权限拒绝、只读 Key 配置、永久失效时间、5 RPM/累计 2 次用量、禁止派生新 Key、额度耗尽拒绝和调用记录展示；前端代理真实 HTTP 验证通过，临时 Key 已撤销。

复制后的系统剪贴板粘贴结果仍需用户人工确认。协议专属适配器仍沿用各自处理逻辑，本轮流错误修复集中在通用 AI 转发路径；未进行真实供应商收费调用或生产部署。

## API Key 列表复制与界面呈现

- 主弹窗以列表为主，创建表单独立；复制入口与 Key 前缀相邻，界面沿用整站 Ant Design 主题，手机端保留清晰的主次信息与可操作按钮。
- 新 Key 保留哈希鉴权，新增独立主密钥加密副本；只允许登录所有者按需取回，复制成功前记录不含秘密的审计。
- 原有哈希 Key 保持可调用，不强制轮换，不能恢复完整值时明确提示重建。
- 人工验收：明暗主题、桌面/窄屏列表、创建/空/加载/错误状态、关闭后重新打开复制、真实剪贴板粘贴、自动复制失败的手动入口、切换身份不处理晚到的敏感响应。

本轮本地验证：后端全量测试通过，覆盖 AES-GCM、所有权、审计失败不披露、旧表升级、旧 Key 鉴权保留及禁止缓存；剪贴板 6 条回归全部通过。真实浏览器验证了完整 Key 与创建值的哈希一致、刷新后再次复制、新建默认权限/RPM、创建错误提示、空列表、复制审计及明暗主题。320/375/414/768 像素下弹窗和卡片操作无横向溢出，关闭按钮为 44×44 像素。自动复制的失败和晚到身份分支通过模拟测试，未强制修改浏览器权限。
